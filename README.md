# بوت فحص أمني شخصي (Defensive OSINT Bot)

بوت تليجرام يساعدك تتحقق **من بياناتك أنت فقط**:
- هل بريدك الإلكتروني ظهر في تسريب بيانات معروف؟
- هل كلمة المرور اللي تستخدمها مسربة؟

يعتمد على خدمة [Have I Been Pwned](https://haveibeenpwned.com) الموثوقة والمستخدمة من شركات أمنية كبرى حول العالم.

## خطوات التشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إنشاء بوت تليجرام
- افتح تليجرام وابحث عن `@BotFather`
- أرسل `/newbot` واتبع التعليمات
- انسخ الـ Token اللي بيعطيك ياه

### 3. (اختياري) الحصول على المفاتيح
- **HIBP** (فحص البريد الإلكتروني) — مدفوعة (~3.5$/شهر): https://haveibeenpwned.com/API/Key
- **NumVerify** (فحص صحة رقم الهاتف) — فيها باقة مجانية بحد شهري: https://numverify.com

فحص **كلمة المرور** مجاني تماماً ولا يحتاج أي مفتاح.

### 4. ضبط متغيرات البيئة
```bash
export TELEGRAM_BOT_TOKEN="ضع_التوكن_هنا"
export HIBP_API_KEY="ضع_مفتاح_HIBP_هنا"           # اختياري
export NUMVERIFY_API_KEY="ضع_مفتاح_NumVerify_هنا"  # اختياري
```

### 5. تشغيل البوت
```bash
python bot.py
```

## الأوامر
| الأمر | الوظيفة |
|---|---|
| `/start` | شرح البوت |
| `/checkemail you@example.com` | فحص بريدك الإلكتروني |
| `/checkpassword YourPassword` | فحص كلمة مرورك (بأمان، عبر k-anonymity) |
| `/checkphone +9665XXXXXXXX` | تحقق من صحة رقم هاتفك (الدولة، المشغّل) — ليس فحص تسريب |
| `/securitycheck` | خطوات تتأكد فيها بنفسك من أمان حسابك على تليجرام (الجلسات النشطة، 2FA) |

## ملاحظة عن فحص الهاتف
لا توجد خدمة موثوقة تفحص "تسريب" رقم الهاتف تحديداً مثل HIBP للإيميل. أمر `/checkphone` يتحقق فقط من صحة تنسيق الرقم والدولة والمشغّل. أما التأكد الحقيقي من اختراق الحساب فهو عبر `/securitycheck` الذي يوجّهك للتحقق داخل تطبيق تليجرام نفسه (الجلسات النشطة).

## ملاحظات أمنية
- فحص كلمة المرور لا يرسل كلمة المرور كاملة للخدمة — فقط أول 5 أحرف من الـ hash (SHA-1)، وهذا معيار HIBP الرسمي وآمن تماماً.
- البوت يحذف رسالة كلمة المرور من الشات تلقائياً بعد إرسالها لتقليل الأثر.
- استخدم هذا البوت لبياناتك الشخصية فقط.

## النشر (Deployment)
تقدر تشغّله محلياً، أو تنشره على خدمة زي Railway أو Render أو VPS خاص فيك. البوت يستخدم Polling (ما يحتاج دومين أو webhook).
